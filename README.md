# 九阴真经 · 全服公示期角色查询书签

## 功能说明

这是一个浏览器书签脚本（Bookmarklet），在九阴真经集市页面右侧弹出查询面板，将全服所有公示期角色集中展示，并对比历史成交价，方便筛选高性价比账号。

### 核心功能
- **全服查询**：自动翻页获取所有服务器的全部公示期角色，无需逐个切换服务器
- **价格对比**：自动获取每个角色最近3次历史成交价，计算当前价与上次成交价的涨跌幅和差额
- **多维筛选**：支持服务器、门派、等级、关键词、价格区间多重筛选
- **多维排序**：按降价幅度、价格、服务器、成交时间、公示剩余时间排序
- **收藏/忽略**：收藏角色置顶显示，忽略不感兴趣的角色，数据存在本地浏览器
- **右键菜单**：打开原生详情、收藏/取消、忽略、复制角色名
- **视觉提醒**：降价20%以上绿色高亮，快到期橙色边框提醒
- **其他**：导出CSV、自动刷新、记住筛选偏好、精确倒计时显示

## 使用方法

### 第一步：添加书签（以谷歌浏览器为例）
1. 复制 `bookmarklet.js` 文件中的全部内容
2. 右键点击浏览器书签栏 → "添加网页" / "添加页面"
3. 名称填：`九阴全服角色查询`
4. 网址/URL 粘贴下面的代码
5. 点击保存

### 第二步：使用
1. **不用自己先打开集市页面**，在任何页面直接点击书签栏上的「九阴全服角色查询」书签
2. 第一次点击会自动跳转到集市公示期页面
3. 页面加载完后，**再点一次同一个书签**，右侧就会自动弹出查询面板

> 小技巧：
> 1. 关闭面板后，屏幕最右侧会出现一个红色小竖条，点击即可重新拉出查询面板，不用每次点书签
> 2. 按住面板顶部标题栏，可以左右拖动面板到屏幕任意位置，靠近边缘会自动吸附

## 常见问题

1. **数据存在哪里？**
   收藏、忽略、筛选偏好都存在你浏览器的 localStorage 里，不会上传到任何服务器，换浏览器会丢失。

2. **为什么点了书签没反应？**
   - 如果你不在公示期页面，**第一次点击会自动跳转到公示期页面**，这是正常现象
   - 等页面加载完成后，**再点一次同一个书签**，面板就会自动弹出来了
   - 如果你已经在公示期页面，点一次就会直接弹面板

3. **打开详情弹窗被面板挡住怎么办？**
   详情弹窗层级比面板高，会显示在面板上面，不会被挡住。
